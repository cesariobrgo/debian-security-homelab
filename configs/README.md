# Configuraciones de ejemplo (sin datos reales)

Este directorio contiene únicamente plantillas y convenciones. **No** subir:

- `/opt/AdGuardHome/AdGuardHome.yaml` real (puede contener datos sensibles).
- Configuraciones con contraseñas, claves Tailscale/WireGuard, tokens o identificadores reales.
- Capturas o exportaciones de DHCP con MAC/IP de dispositivos.
- Logs DNS completos, ficheros de cookies o certificados privados.

Usar `variables.example.env` como recordatorio de valores a guardar localmente; no es un script para automatizar las instalaciones.
